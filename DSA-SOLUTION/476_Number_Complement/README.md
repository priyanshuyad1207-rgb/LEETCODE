# 476. Number Complement

## 📌 Problem

**LeetCode Problem:** [0476-Number-Complement](https://leetcode.com/problems/complement-of-base-10-integer/)

## 📌 Problem Description

Given a positive integer `num`, return its complement.

The complement of an integer is obtained by flipping all the bits in its binary representation:

* Change `0` to `1`.
* Change `1` to `0`.

**Example:**

Input: `num = 5`

Binary representation: `101`

Complement: `010`

Output: `2`

## 💡 Approach

1. Convert the number into its binary representation.
2. Flip all the bits of the binary representation.
3. Convert the resulting binary number back to decimal.
4. Return the result.
